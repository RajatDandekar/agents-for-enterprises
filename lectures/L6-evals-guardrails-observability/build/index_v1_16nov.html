Build it once by hand: a tracer in twenty lines

ledgerline/course/l6/minitrace.py. A context manager opens a span, finds its parent, closes it, keeps it.

minitrace.pyclass MiniTracer:
    def __init__(self):
        self.spans = []

    @contextlib.contextmanager
    def span(self, name, **attributes):
        parent = _current.get()          # who is running now?
        s = {"name": name,
             "trace_id": parent["trace_id"] if parent else token_hex(16),
             "span_id": token_hex(8),
             "parent_id": parent["span_id"] if parent else None,
             "start": time.time(), "end": None,
             "attributes": attributes, "status": "OK"}
        token = _current.set(s)          # children find me
        try:
            yield s
        except Exception as e:
            s["status"] = f"ERROR: {e}"; raise
        finally:
            s["end"] = time.time()
            _current.reset(token)
            self.spans.append(s)

What goes in a span, and what must not

A trace of an agent holds prompts, replies, tool results: customer data, prices, names. Decide before you ship.

Content is opt-in

Off by default

The conventions keep messages out unless you set OTEL_INSTRUMENTATION_GENAI_CAPTURE_CONTENT (NO_CONTENT, SPAN_ONLY, EVENT_ONLY, SPAN_AND_EVENT). Debugging needs it; privacy may forbid it.
Redact before it leaves

Mask in the process

Our tracer takes redact=: Presidio masks card numbers, IBANs, phone numbers before export. In our attack run, a card number typed in chat stayed out of the trace with it on.
Keep it as long as needed

Retention and access

Traces are data under GDPR like any log: a retention period, who may open them, deletion on request. Langfuse Hobby keeps 30 days.
In our build Content on (it is a sandbox, all names fictional), Presidio redaction when the PII guard is on, public links only for the course project.

What an eval adds

Eval A test for behaviour that is not a fixed output: a known input, written criteria, a scorer (code, a model or a person) and a threshold that decides pass or fail.

An eval has four parts

Before writing evals: read the traces

Error analysis, what practitioners do first: look at many real failures, name them in your own words, then count.

Why first: generic metrics (“helpfulness 4.2/5”) measure what is easy, not what breaks. The categories come from your traces. Ours did: our first suite run failed of runs, and we read every one.

The incident’s guard, in code

Runs before every commit. It does not ask the model whether Emma agreed; it looks at what Emma typed and what she was shown.

guards.pyYES = re.compile(r"\b(yes|go ahead|confirm(ed)?|please do|ok|sure|...)\b")
NO  = re.compile(r"\b(no|not yet|don't|wait|hold off|stop|cancel)\b")

def on_input(self, agent, text, rec):        # Emma's message
    self.turn += 1
    if YES.search(text) and not NO.search(text):
        self.yes_turns.append(self.turn)      # recorded by code

def after(self, agent, name, args, out, rec): # a tool result
    if out.get("ok") and "preview" in out:
        self.previewed.setdefault(signature(name, args), self.turn)

def before(self, agent, name, args, rec):    # a tool call
    if name in COMMITS and args.get("confirm") is True:
        seen = self.previewed.get(signature(name, args))
        if seen is None or seen >= self.turn or self.turn not in self.yes_turns:
            return {"ok": False, "refused_by": "guard: confirm_yes",
                    "error": "No preview shown to Emma in an earlier turn.",
                    "next_step": "Preview with confirm=false and ask Emma."}
The refusal goes back to the model as a tool result, with a next step, so it recovers: it shows the preview and asks.
A guard has bugs too: our first version overwrote the preview’s turn when the agent previewed again after the yes, and refused Emma’s real yes. The replay found it (setdefault is the fix).

What can still go wrong

“Yes, but not today”

Our yes detector is a rule; a clever “no” passes it. A real system shows a button: the yes is a click, not a sentence.
Small sets

20 tasks, 41 texts

Re-calibrate

Guards only see tool calls

A tool that does too much at once (no preview) cannot be guarded well. Fix the tool.
