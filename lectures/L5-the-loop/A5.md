In class you built Emma's order twice in Daedalus: as a workflow (written-down blocks) and as an agent (a model in a
loop, inside a harness), and raced them on six jobs. Now do the same for **your own module**, with the tools you built

Start from the cells marked **A5** at the end of `NB5_the_loop.ipynb`. It runs on free Colab; recorded replies replay

## Part 1 · The workflow (30 points)
1. Pick **one job** in your module that people do often (for example: raise a leave request, book a delivery, register
   a supplier). Write its steps as a list of blocks, the way `ledgerline.daedalus.workflow.SHIPPED_BLOCKS` does.
2. At most **one model step**, to turn the person's words into fields. Every other step is a tool from your A4
   toolbox, a gate, an approval step or a reply.
3. A **gate** for every rule that must never break (in Emma's: the UN 38.3 certificate, a closed cost centre). Say in
   one line each why it is a gate and not a line in a prompt.
4. If a person must sign, an **approval step** that saves the run as JSON and resumes only when your system of record
   says it is approved. Show one run that waits, the saved JSON's size, and the resume.
5. Run it twice on the same input and show that nothing is created twice.

## Part 2 · The agent (30 points)
1. The same job on `ledgerline.daedalus.loop.Agent` with your tools (`ledgerline.course.l5.kit.FolderToolbox`).
2. Set **every harness knob** and justify each with a measurement: max steps, token budget, which tools, the system
   prompt, the approval pause, error recovery. ("Max steps 8, because my longest correct run used 6 model calls.")
3. Turn one knob too tight on purpose and show what breaks, with numbers.

## Part 3 · The race (25 points)
1. Write **six jobs** of your own: two plain ones, two traps (a rule that must stop the job), one that needs a
   judgement nobody wrote down, and one plain question.
2. Write a `score()` that reads your system's **tables**, never the model's words (except for the question).
3. Race the workflow (once) and the agent (three times). Report a table: right, model calls, tool calls, tokens,
   seconds, and whether the agent took the same path each time.

## Part 4 · One honest failure (15 points)
Find one case where your harness or your workflow does the wrong thing (in class: our own recovery rule refused a safe
retry after a lost reply). Show it with a number, fix it, and show the number again.
