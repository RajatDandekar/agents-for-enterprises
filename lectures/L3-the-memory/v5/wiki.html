Andrej Karpathy, “LLM Wiki”, a GitHub gist, April 2026: gist.github.com/karpathy LLM Wiki

  • Title→one page per entity, named by a slug
  • Lead→the summary in the page’s front matter
  • Infobox→the fact table at the top of a page
  • Contents→fixed sections per page type
  • Blue links→[[wikilinks]] between pages
  • [1] [2]→references to the raw source and page
  • “Needs citations”→lint findings
  • View history→log.md, append-only
  • Search→index.md, the catalogue read first
