# Tax Codes and Payment Terms

This page details the GST tax codes and supplier payment terms used in Bahi ERP. It guides purchase executives on selecting the correct tax codes for intrastate and interstate suppliers. It also defines the standard codes for invoice-based and advance payments.

## Rules

- Effective from 2026-04-01, suppliers in Maharashtra are charged CGST + SGST using tax codes ending in -INTRA, while suppliers in any other state are charged IGST using tax codes ending in -INTER [POL-PUR-001 §8.1].
- Use tax code GST18-INTRA for CGST 9% + SGST 9% when a supplier is in the same state as the organisation unit [MAN-DD-72 §7.1].
- Use tax code GST18-INTER for IGST 18% when a supplier is in another state [MAN-DD-72 §7.2].
- Use tax codes GST12-INTRA and GST12-INTER for the same intrastate and interstate rules at a 12% rate [MAN-DD-72 §7.3].
- Use payment term codes N30, N45, or N60 for net payment at 30, 45, or 60 days from the invoice [MAN-DD-72 §8.1].
- Use payment term code ADV for advance payments [MAN-DD-72 §8.1].
