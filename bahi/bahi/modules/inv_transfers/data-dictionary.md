# Inventory · transfers: data dictionary

Prefix `tr_` for services, `sp_tr_` for stored procedures, `tr_` for tables. Every reply comes in the legacy envelope `{rc, err_cd, msg, data}`; rc is S, W or E.

## Services

| Service | Legacy name | Kind | Screen | Fields (* = mandatory) |
|---|---|---|---|---|
| `tr_stk_enq` | STOCK BY LOCATION | read | INV-STK-07 | itm_cd*:str, whs_cd:str |
| `tr_fetch` | TRANSFER DEFAULTS | read | INV-TRN-04 | itm_cd*:str, from_whs*:str, to_whs*:str |
| `tr_save` | TRANSFER NOTE SAVE | write | INV-TRN-04 | itm_cd*:str, qty*:int, from_whs*:str, to_whs*:str, slot:str, vehicle:str, ewb_no:str, fwd_to:str, remarks:str, fetch_tok:str, client_ref:str |
| `tr_list` | TRANSFER NOTE LIST | read | INV-STK-07 | tn_no:str, itm_cd:str, status:str, to_whs:str, approver:str, client_ref:str |
| `tr_approve` | NIGHT TRANSFER APPROVE | write | INV-TRN-04 | tn_no*:str, decision*:str, comment:str |
| `tr_gp_create` | GATE PASS CREATE | write | INV-GTP-05 | tn_no*:str, vehicle:str, ewb_no:str |
| `tr_gp_out` | GATE PASS CHECK OUT | write | INV-GTP-05 | gp_no*:str |
| `tr_receive` | TRANSFER RECEIPT | write | INV-GTP-05 | tn_no*:str, qty_rcvd*:int, remarks:str |

## Tables

- **tr_note** (8 seed rows): tn_no, itm_cd, qty, from_whs, to_whs, mv_type, slot, vehicle, basic, gross, ewb_no, status, approver, created_by, created_on, warn_cd, client_ref, remarks
- **tr_gp** (4 seed rows): gp_no, tn_no, gp_type, vehicle, ewb_no, status, created_by, created_on, out_by, out_on
- **tr_rcpt** (6 seed rows): rc_no, tn_no, qty_rcvd, rcvd_by, rcvd_on, remarks
- **tr_ewb** (3 seed rows): ewb_no, tn_no, gen_by, gen_on, valid_to, value
- **tr_qc_hold** (3 seed rows): itm_cd, whs_cd, lot, qty, reason, held_on, release_due, status
- **tr_std_rate** (10 seed rows): itm_cd, rate, valid_from
- **tr_vehicle** (4 seed rows): veh_no, descr, owner, ou_cd, capacity_kg
- **tr_route** (4 seed rows): from_whs, to_whs, km, transit_hrs

## Field meanings

| Field | Meaning |
|---|---|
| `itm_cd` | Item code. GSK-SIL-05L is the 5-litre silicone gasket; GSK-SIL-05L-R is the rework lot, not for the line. |
| `from_whs / to_whs` | Warehouses: WH-CHK-STR Chakan stores, WH-PUN-STR Pune main stores, WH-PUN-LN5 the 5-litre line-side store. |
| `mv_type` | INT = inside one unit (no gate pass). IUT = between units (gate pass; e-way bill above Rs 50,000). |
| `slot` | DAY or NIGHT. A NIGHT move between units needs approval before a gate pass. |
| `vehicle` | Vehicle number from the vehicle master (tr_vehicle). |
| `ewb_no` | E-way bill number (12 digits), generated by logistics on the government portal. Bahi checks only the format. |
| `fwd_to` | FWD TO: sends a night move to this approver instead of the one Bahi picks. |
| `fetch_tok` | Token from Fetch (tr_fetch). Save without it fails with ERR-SCR-0221. |
| `free` | On hand - allocated - QC hold. Only free stock can move. |
| `qty_rcvd` | Quantity physically counted in at the receiving store. |
| `client_ref` | Free text the caller can use as an idempotency key. |

## Status codes

**SH** short: saved, but part of the quantity is QC-held; waits, never gets a gate pass · **PA** night move waiting for approval · **AP** approved, ready for a gate pass (or, inside one unit, to receive) · **IT** in transit: left the issuing gate, not yet received · **RC** received · **RJ** rejected · **CN** cancelled · **OP (gate pass)** gate pass created, not yet out · **OUT (gate pass)** checked out at the gate
