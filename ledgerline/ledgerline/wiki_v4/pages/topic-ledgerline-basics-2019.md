This topic covers the superseded 2019 IT induction training deck for Ledgerline new starters. The material reflects historical system conventions and onboarding instructions from 2019 rather than active procedures in force today. It is retained for reference when reviewing legacy documentation and historical system practices.

## Overview of 2019 Induction Guidance

In the superseded 2019 training material, new employees were instructed to obtain their Ledgerline user ID directly from IT [^r1]. System security rules outlined in the deck mandated that Ledgerline passwords be a minimum of 8 characters in length and updated every 90 days [^r2].

The deck detailed standard screen navigation, specifying function key F2 for lookups and function key F8 for Save operations across Ledgerline screens [^r3]. On the order screen, the F3 Fetch key was designated as optional [^r4]. For technical support and onboarding assistance, the IT service desk contact was listed as extension 2210 [^r5].

## Versions and conflicts

- **Current onboarding rules versus 2019 induction procedures**: Today's active IT and Ledgerline procedures govern user setup and interface controls; the 2019 deck instructed users to obtain IDs from IT, enforce 8-character passwords expiring every 90 days, treat F3 Fetch as optional on order screens, and call extension 2210 for support (`superseded`; 11_training/old/Ledgerline basics for new starters (2019) deck export.pdf) [^r1][^r2][^r3][^r4][^r5].
