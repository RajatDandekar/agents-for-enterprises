On 5 March 2026, the Change Advisory Board approved change request CR-2026-007 to install Ledgerline ERP patch 7.2.3-P2 on the evening of 8 March 2026 [^r1]. Under this decision, the central server system parameter file idle threshold was amended to reduce the core application session inactivity timeout from 20 minutes to 15 minutes [^r2]. This change ensures that unattended shared workstations automatically disconnect while cleanly rolling back uncommitted database transactions [^r3][^r4].

## Context and discussion

The CAB session on 5 March 2026 was attended by [[user-rpryce|Rhys Pryce]], Joanna Fletcher, and Daniel Okafor [^r1]. The reduction of the inactivity period to 15 minutes was introduced because unattended terminals and shared workstations on the shop floor in both the Manchester plant and the Leeds unit were left signed in during busy shifts [^r3]. When an idle terminal disconnects under this rule, Ledgerline ERP cleanly rolls back uncommitted entries so that open records are not corrupted [^r4].

## Implementation

The CAB scheduled the [[rn-7-2-3-p2|7.2.3-P2]] update script outside normal operating hours for the evening of 8 March 2026 on the central server [^r1][^r5]. The board required an advance advisory note via e-mail informing staff of the revised timeout behaviour prior to deployment [^r5]. The amended idle threshold configuration applies across the core system environment described in [[man-adm-72|MAN-ADM-72 Ledgerline ERP 7.2 System Administration]] [^r2].
