W-SUP-0207 is an advisory status bar message delivered in [[rn-7-2-3-p4|RN-7.2.3-P4]] that flags missing or expired UN 38.3 battery transport test records during purchase order save [^r1][^r2]. The prompt is controlled by parameter `PUR.CERT_CHK`, which is currently kept set to `N` at Northbridge Cycles, leaving the warning inactive [^r3][^r5]. Because it functions strictly as an advisory notice checking only the vendor record's valid-to date, it does not evaluate full policy requirements or block the order from saving [^r2][^r4].

## Meaning

W-SUP-0207 displays the text `UN38.3 CERTIFICATE MISSING OR EXPIRED` on the status bar when the supplier record lacks an active UN 38.3 transport testing certificate covering the order date [^r1].

## Cause

The warning is triggered when setting `PUR.CERT_CHK` is configured to `Y` and the purchase order references a supplier with no [[topic-un-38-3-certificates|UN 38.3 certificate]] whose valid-to date falls on or after the order date [^r1][^r3].

## How to fix

As an advisory message, W-SUP-0207 does not abort or prevent saving the purchase order to the database [^r2][^r4]. To prevent the prompt when active, the vendor record must be updated with a valid-to date on or after the order date [^r1][^r4]. The check evaluates only this master record date and does not validate the 12-month or 60-day compliance rules defined under [[amd-sup-2026-02|AMD-SUP-2026-02]] [^r4]. At Northbridge Cycles, parameter `PUR.CERT_CHK` remains set to `N`, so the message is not currently triggered during order entry [^r5].

## Raised by

The warning is raised on screen [[screen-pur-po-01|PUR-PO-01]] during the order save operation when parameter `PUR.CERT_CHK` is enabled [^r1][^r3].

## Versions and conflicts

* **Today's rule:** Parameter `PUR.CERT_CHK` is set to `N`, leaving warning W-SUP-0207 inactive pending Change Advisory Board (CAB) re-evaluation in January 2027 under [[decision-2026-10-07-cr-2026-031-cert-check|CR-2026-031]] [^r5].
* **System capability:** Patch 7.2.3-P4 introduced the message as an optional check whenever `PUR.CERT_CHK` is set to `Y` [^r1][^r3].
* **Kind:** `future_dated`
