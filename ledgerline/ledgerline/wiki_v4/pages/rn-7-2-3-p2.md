Ledgerline ERP patch release 7.2.3-P2 took effect on 9 March 2026 under document code RN-7.2.3-P2, having been deployed to the central server on 8 March 2026 [^r1][^r2][^r7]. The patch reduced the system idle session timeout from 20 minutes to 15 minutes and updated user lockout handling in administrative screens and Active Directory authentication [^r3][^r4][^r5]. It also introduced known issues affecting financial report print layouts, parts lookup responsiveness, and overnight batch posting temporary table space [^r6].

## Changes
The default idle-session timeout parameter `SYS.SESSION_TIMEOUT` was reduced from 20 minutes to 15 minutes in patch 7.2.3-P2, although standard user manuals were not reissued to reflect this update [^r3]. Locked user identifiers are displayed in the locked users report instead of appearing alongside active accounts in the general user maintenance screen [^r4]. When an account is suspended or exceeds failed logon thresholds, the authentication service suppresses Active Directory handshakes until cleared by an administrator [^r5].

Known issues identified in patch 7.2.3-P2 include layout irregularities on printed financial reports, reduced response times on the general parts lookup screen for large assemblies, and transient temporary table space warnings during overnight purchase invoice posting batch runs [^r6].

## Effect at Northbridge
The Change Advisory Board approved patch 7.2.3-P2 under [[decision-2026-03-05-cab-cr-2026-007|CR-2026-007]] on 5 March 2026 for central server installation on the evening of 8 March 2026 [^r7]. In conjunction with the patch installation, the system parameter file idle threshold was modified to change the session timeout from 20 minutes to 15 minutes [^r8]. The patch was installed on 8 March 2026 by [[user-jfletcher|Joanna Fletcher]], recorded under entry NBC-2026-004 in the [[data-nbc-change-log|NBC customisations and patch log]], causing idle Ledgerline sessions across the company to terminate after 15 minutes [^r1][^r9].

## Versions and conflicts
* **System idle timeout**: Ledgerline closes idle user sessions after 15 minutes following the patch installation on 8 March 2026 and parameter update under RN-7.2.3-P2 [^r1][^r3][^r8][^r9]. The standard user manuals describe a 20-minute idle session timeout and were not updated [^r3]. Kind: superseded.
