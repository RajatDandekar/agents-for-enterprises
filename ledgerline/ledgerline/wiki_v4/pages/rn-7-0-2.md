Ledgerline ERP 7.0.2 was issued on 30 November 2015 as a maintenance release across Northbridge Cycles' Manchester works and Leeds unit [^r1]. It introduces client reference search capabilities in purchasing order lists and returns unspent budget balances in finance validations [^r2][^r4]. It also documents specific known issues affecting pre-printed stationery alignment, unfiltered item searches, and multi-desk dispatch spooling [^r6][^r7][^r8].

## Changes

The purchasing order list screen incorporates direct filtering by client reference, permitting searches across open, held, and completed states by bike shop or partner references [^r2]. Any integrations generating supplier orders from customer commitments must populate the client reference field during transmission to avoid manual correction during order list searches [^r3].

In the finance module, the budget check routine returns the unspent available balance in pounds within the enquiry sub-panel, rather than merely confirming whether remaining funds exist [^r4]. External utilities and integrations that call this budget validation routine must handle the expanded data structure that returns this available balance value [^r5].

## Effect at Northbridge

The update was applied across both the Manchester works and the Leeds unit [^r1]. Several operational issues were identified in this release:

* Printing purchase orders onto pre-printed office stationery can encounter address block shift distortion when using alternate printer drivers, requiring generation on plain paper pending an updated print definition [^r6].
* Searches performed within the item lookup screen across large component databases display sluggish performance when run without category filters [^r7].
* Generating combined dispatch summaries for retailer shipments can trigger print queue spooling delays when multiple distribution desks submit jobs at the same time [^r8].
