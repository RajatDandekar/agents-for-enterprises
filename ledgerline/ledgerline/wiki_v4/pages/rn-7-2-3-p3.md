Ledgerline ERP patch release 7.2.3-P3 was issued on 22 June 2026 as a maintenance update across inventory and accounts payable routines [^r1]. Today, committing a goods receipt that fulfills an outstanding order balance automatically closes the purchase order to status closed (CL), locking it from further receipt postings or amendments [^r2][^r4]. In accounts payable, the update halts duplicate invoice registration by raising [[err-inv-0118|ERR-INV-0118]] whenever an entered supplier invoice reference already exists for that vendor account [^r5].

## Changes

In inventory routines, committing a goods receipt that fulfills an outstanding order balance immediately closes the purchase order and sets its header status to closed (CL) without requiring manual closure or overnight batch processing [^r2]. Once a purchase order advances to closed (CL), order line items are marked as fulfilled and the document is locked against further receipt postings or buyer amendments [^r4]. Purchase orders that were fully delivered prior to the installation of patch 7.2.3-P3 are not adjusted retrospectively and must be closed manually [^r3].

In accounts payable, entering a supplier invoice reference that already exists for that vendor account triggers error [[err-inv-0118|ERR-INV-0118]], halting processing and refusing duplicate invoice registration [^r5]. When [[err-inv-0118|ERR-INV-0118]] is triggered, the document remains unposted, batch totals do not increment, and the cursor returns to the reference field [^r6]. Inbound automated feeds and batch transfers attempting to post a repeated supplier invoice number fail validation with [[err-inv-0118|ERR-INV-0118]] and must be routed to an interface error queue [^r7].

The release includes several known operational issues [^r8]. Works order assembly summary sheets rendered on dot-matrix printers may display slight column misalignment and truncated component descriptions following the patch [^r8]. Stock register lookups across broad assembly categories experience noticeable retrieval delays across the wide area link unless specific initial description text is entered instead of wildcards [^r9]. Additionally, batch output files generated for transfer into external spreadsheets occasionally omit trailing carriage returns on the final record [^r10].

## Effect at Northbridge

Warehouse and purchasing personnel no longer need to execute manual close actions or await overnight batch routines for orders fully satisfied by receipt transactions [^r2]. However, buyers and inventory clerks must manually close any purchase orders that were fully delivered before 22 June 2026 [^r1][^r3].

Accounts payable processing under [[sop-ap-001|SOP-AP-001]] is safeguarded against duplicate registration by system-level validation, requiring staff to re-check invoice references when the cursor is returned to the entry field [^r5][^r6]. Automated batch imports encountering duplicate numbers require manual intervention within the interface error queue [^r7]. Production and inventory staff must use explicit description terms rather than wildcards when searching broad assembly categories over wide area links to avoid lookup delays, and printouts on dot-matrix devices should be checked for truncated component descriptions [^r8][^r9].
