Ledgerline ERP 7.0.1 is a maintenance release issued on 15 June 2015 for all Ledgerline 7 customers across the Manchester works and Leeds unit [^r1]. It introduces an F2 rate history lookup within purchase order entry to view past agreed unit prices from settled orders, as well as default newest-first ordering for stock ledger inquiries [^r2][^r3].

## Changes

Pressing F2 in the Rate field of [[screen-pur-po-01|screen PUR-PO-01]] invokes a rate history lookup that allows buyers to view earlier agreed unit prices from settled purchase orders [^r2]. If no prior purchase orders exist for the selected item and supplier combination when F2 is pressed, the system displays an informational message and leaves the cursor in the Rate field [^r4].

The stock ledger enquiry display defaults to sorting inventory movement records newest transactions first [^r3].

Known issues identified in the release include:
* Works order variance report column headings become misaligned on subsequent pages when run across several production batches [^r6].
* Part lookup on screen PUR-PO-01 exhibits delays when browsing large stock categories, which users can bypass by entering initial description characters [^r7].
* The stock ledger inquiry screen may show a newly received material's status as pending inspection until the window is closed and reopened, although stock balances update immediately [^r8].

## Effect at Northbridge

External integrations extracting stock ledger data must explicitly sort queries or payloads if they require chronological ascending order, because default query services return records sorted newest first [^r5].
