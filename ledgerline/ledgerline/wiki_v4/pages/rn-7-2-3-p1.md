Ledgerline ERP 7.2.3-P1 is a maintenance patch released on 23 June 2025 that applies across the Manchester works and the Leeds unit [^r1]. It updates the wording of purchasing error [[err-po-0412|ERR-PO-0412]] to reference supplier country rather than state, adds the creator identifier to standard purchase order enquiries, and documents several operational known issues [^r1][^r2][^r3][^r4][^r5][^r6]. As of 26 October 2026, its modifications to error messaging and service output structures remain in force across all operating sites [^r1][^r2][^r3].

## Changes

Patch 7.2.3-P1 modifies the error message text for [[errors-po|ERR-PO-0412]] from 'TAX REGION DOES NOT MATCH SUPPLIER STATE' to 'TAX CODE DOES NOT MATCH SUPPLIER COUNTRY', appending the supplier's country code in brackets at the end of the line while keeping the underlying tax validation rule unchanged [^r2]. Additionally, the purchase order enquiry service `po_search` within [[services-pur-po|PUR po services]] returns `created_by` in its standard output dataset [^r3].

## Effect at Northbridge

The change to [[err-po-0412|ERR-PO-0412]] clarifies tax code discrepancies on international orders across purchasing teams without altering existing validation controls [^r2]. The addition of `created_by` to `po_search` provides direct visibility of document originators in standard enquiry routines [^r3].

Known issues identified in the release affect site operations:
* At the Leeds site, direct line-printer output for the standard works order summary report may misalign column headers and overlap description field text onto the adjacent quantity column [^r4].
* At the Manchester works, inventory searches pause temporarily when querying parts lists with extensive transaction histories while stock records populate [^r5].
* When matching debit notes against supplier accounts that have numerous unpaid entries, the purchase ledger allocation window intermittently fails to refresh the running balance display, requiring operators to reopen account enquiry to view the updated position [^r6].
