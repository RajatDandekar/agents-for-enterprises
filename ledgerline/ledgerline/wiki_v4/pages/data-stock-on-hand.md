`Stock_on_hand_2026-10-26_0900.xlsx` provides an inventory status snapshot extracted from Ledgerline ERP via `stk_query` as of 26 October 2026 at 09:00[^r1][^r12]. It records current stock quantities across four company warehouses covering 2,080 distinct item codes[^r2][^r9]. Because inventory transactions occur continuously throughout the working day, these snapshot figures reflect system balances specifically at 09:00 as noted in [[man-pur-72|MAN-PUR-72]] §4.1[^r12][^r14].

## What it holds

The workbook contains a single sheet named `Stock` capturing inventory balances across Manchester and Leeds facilities[^r1][^r23]. The records span finished goods, maintenance, and raw materials storage, detailing quantities currently physically present, reserved for existing demand, or awaiting receipt from vendors[^r1][^r2].

Inventory balances cover all active item families, including frames ([[items-frm|FRM-*]]), wheel components such as spokes ([[items-spk|SPK-*]]) and tyres ([[items-tyr|TYR-*]]), brake components ([[items-brk|BRK-*]]), handlebar grips ([[items-grp|GRP-*]]), accessories ([[items-acc|ACC-*]]), and fasteners ([[items-fst|FST-*]])[^r4][^r16][^r18][^r22][^r25][^r26][^r27]. Earlier the same morning at 06:15, batch job JOB-INV-040 printed report INV-R002 (Stock Status, All Items, All Warehouses) across 56 pages covering these warehouses and items[^r31][^r32].

## Columns

The `Stock` sheet contains 6 columns across each record[^r1][^r15]:

| Column | Description |
|---|---|
| `line` | Sequential row counter within the extract[^r1][^r15]. |
| `itm_cd` | Northbridge item code identifier[^r1][^r15]. |
| `whs_cd` | Warehouse location code (`WH-LDS-STR`, `WH-MAN-FG`, `WH-MAN-MRO`, or `WH-MAN-STR`)[^r1][^r2][^r15]. |
| `on_hand` | Physical stock quantity currently in the warehouse[^r1][^r15]. |
| `allocated` | Stock quantity committed or allocated to production or sales orders[^r1][^r15]. |
| `on_order` | Stock quantity outstanding on open purchase orders[^r1][^r15]. |

## How to look up a row

Look up records in the `Stock` sheet using the compound key of item code and warehouse code (`itm_cd` + `whs_cd`)[^r4][^r10][^r15]. For example:
* Looking up `FRM-ANC-S-BLK` at `WH-MAN-STR` shows 11,764 on hand, 343 allocated, and 4,000 on order[^r4].
* Looking up `FRM-MED-L-SLV` shows 4,021 on hand, 1,173 allocated, and 4,000 on order at `WH-MAN-STR`, alongside 2,607 on hand at `WH-LDS-STR`[^r10].
* Looking up `SPK-14G-254` at `WH-MAN-STR` shows 17,600 on hand, 2,185 allocated, and 9,000 on order[^r18].
* Looking up `FST-BLT-M3X12-ZN` shows 119,476 on hand, 7,762 allocated, and 0 on order at `WH-MAN-STR`, and 20,944 on hand, 0 allocated, and 0 on order at `WH-LDS-STR`[^r30].

## Size

The extract consists of 2,338 data rows spanning 2,080 distinct item codes across 4 warehouse locations[^r1][^r2][^r9].
