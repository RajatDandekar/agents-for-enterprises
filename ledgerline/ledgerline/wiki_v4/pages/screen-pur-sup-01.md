Screen PUR-SUP-01 is the Ledgerline screen used to create new supplier master records following written approval from the purchase manager [^r1][^r17]. Upon record creation, Ledgerline automatically assigns the supplier an ACTIVE status without requiring documentation [^r2][^r9][^r18]. It also hosts a Certificates tab for uploading compliance documentation such as [[topic-un-38-3-certificates|UN 38.3]] test reports [^r5][^r10].

## Fields

PUR-SUP-01 is accessible via the menu path Masters > Supplier create by roles [[role-pur-exec|PUR-EXEC]], [[role-pur-sr|PUR-SR]], and SYS-ADMIN [^r12].

The entry fields on the screen include:
* **Supplier name (`name`)**: Required field containing the supplier's trading name [^r6][^r13].
* **City (`city`)**: Required field indicating the supplier's city [^r6][^r13].
* **Country code (`state`)**: Required two-letter country code [^r6][^r13].
* **VAT number (`vat_no`)**: Optional field entered without spaces [^r4][^r6][^r13]. Duplicate checks only run against this field; leaving it blank bypasses system duplicate detection [^r8][^r15].
* **Payment terms (`pt_cd`)**: Optional field indicating agreed payment terms, which defaults to N30 [^r4][^r6][^r13].
* **Supplier code (`sup_cd`)**: Read-only field automatically generated by Ledgerline upon saving using the initials of the supplier name, the first three letters of the city, and a sequential number [^r7][^r13].

On the Certificates tab, fields include Certificate type (such as UN38.3), Document reference, Valid to date, and an attached scan of the test report [^r5][^r10]. Expired certificates display with a red valid-to date on this tab, though Ledgerline does not block purchase orders for suppliers with expired certificates [^r11].

## Keys and services

* **F8**: Triggers the write service `sup_create` (endpoint `POST /ll72/svc/sup_create`) using the supplier name, city, two-letter country code, VAT number without spaces, and payment terms [^r4][^r14][^r16].
* **Save Certificate**: Executes service `sup_cert_upload` to store the certificate type, document reference, valid-to date, and scanned file [^r5].

## Messages

* **`SUPPLIER <code> CREATED`**: Status bar confirmation returned after service `sup_create` successfully saves the new supplier record [^r4][^r9].
* **`CERT SAVED`**: Status bar message confirming that service `sup_cert_upload` has saved the certificate [^r5][^r10].
* **[[err-sup-0118|ERR-SUP-0118]]**: Error thrown when attempting to register a VAT registration number that already exists in Ledgerline [^r3][^r8][^r15][^r16].

## Versions and conflicts

Under current policy [[pol-sup-003|POL-SUP-003]] v2.3 and [[sop-pur-001|SOP-PUR-001]] v3.1, screen PUR-SUP-01 is used by authorised users once the onboarding file has received written approval from the purchase manager, immediately assigning ACTIVE status upon creation [^r1][^r2][^r17][^r18]. Under superseded policy POL-SUP-003 v2.2 (in [[pol-pur-001|POL-PUR-001]]), creation on PUR-SUP-01 required collecting company registration, VAT certificate, insurance, bank letter, and a signed Code of Conduct prior to creation [^r19][^r20].
