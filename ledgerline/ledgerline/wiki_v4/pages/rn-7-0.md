Ledgerline ERP 7.0 was deployed across Northbridge Cycles sites in Manchester and Leeds on 2 March 2015 as a major platform release[^r1]. It established the current order processing architecture by dividing single order workflows into separate screens for entry, approval, and release, while moving approval limits directly onto user profiles[^r2][^r3]. The release also introduced the core HTTP service envelope structure and mapped historical 6.x item numbers to legacy fields[^r4][^r5].

## Changes

Ledgerline 7 retired the combined single order screen from Ledgerline 6.x and divided routine order processing across dedicated screens for initial order entry on [[screen-pur-po-01|PUR-PO-01]], management approval, and final order release[^r2]. Financial and spending approval limits are no longer inherited from system roles; instead, each individual user profile carries an approval limit assigned from the company matrix, as recorded in [[data-users-and-approval-limits|user approval records]][^r3].

The system introduced an HTTP service layer using flat payloads within an envelope structure of `{rc, err_cd, msg, data}`, whilst retaining the 6.x SOAP gateway on port 8091 for EDI, banking, and carrier interfaces[^r4]. In part master records documented in the [[data-item-master|item master]], historical Ledgerline 6 item numbers formatted as `NBnnnnnn` were preserved in a dedicated legacy code field[^r5].

## Effect at Northbridge

The deployment unified operations across both the Manchester and Leeds sites on 2 March 2015[^r1]. Operations identified several initial known issues under release 7.0:

* Column headers misalign on standard ledger summary reports for wide stationery whenever descriptions exceed standard line width[^r6].
* Customer and supplier account lookup lists in sales order processing show degraded performance when filtering the entire active register without entering initial search letters[^r7].
* Despatch notes intermittently truncate delivery address lines by dropping the final street line when special shipping instructions are appended[^r8].
