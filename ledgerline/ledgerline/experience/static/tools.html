The toolbox behind Ask Northbridge

One tool per business activity.

Each tool is a folder: tool.json says what it does and what it needs (that is what the model reads), and tool.py is the code that runs, calling Ledgerline's services as the signed-in person. Try any of them on your own Northbridge.

The same folders feed the chat, the MCP server, the Workflow Studio and this page. All data is fictional.
