# Inter-unit Transfer Procedure (2019, superseded)

**Kept for reference. Where it disagrees with SOP-STR-021 or the Gate Pass Policy, those win.**

1. All transfers from Leeds go to Manchester main stores (WH-MAN-STR); the line collects from there. (The line-side store WH-PUN-LN5 was created in 2026.)
2. Night movements need the stores in-charge's signature on the paper gate pass. (Now the plant head must approve: POL-SEC-004 §4.2.)
3. An e-way bill is needed above £100,000. (Now £50,000 including VAT: FIN-NOTE-012.)
4. The receiving stores may post the receipt when the gate pass is checked out, to save time. (Not allowed now: receipt only after physical count, SOP-STR-021 §6.1.)
