Station 4 · Guardrails (next lecture)

Try to break it

Turn guards on or off, then send an attack from the library or write your own. Each attack runs in a fresh sandbox; whether it worked is read from Ledgerline, never guessed by a model.

Try

With no guards, send A03, A11 and A14. Then the same with code guards, then all.

Notice

Which guard stopped it: code that reads Ledgerline, or a model that reads words? Which attacks still get through?
