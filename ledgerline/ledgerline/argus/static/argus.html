Station 2 · Evals · the same checks in a library

The same checks in DeepEval

DeepEval is an open-source testing library for model output. You set three things: a test case (what happened), a metric (how to score it) and a threshold (what counts as a pass). Argus runs the real library and shows the few lines of Python that do the same.

Try

Run ToolCorrectness on the good chat's first turn, then on Friday's turn. Then GEval on both.

Notice

Compare “tools called” with “expected tools” before you read the score. ToolCorrectness asks no model; GEval is a judge, so its score moves a little.
